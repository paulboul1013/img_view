# image_viewer


## compile
```
make
```

## usage
```
./main test.ppm 
```
or
```
./main < test.ppm
```

## ability

- mouse scroll:change zoom
- left and right mouse: move the img view
- 'r' key: rotate img clockwise 90 degree


## convert png to ppm command
```
sudo apt install imagemagick 
convert test.png test.ppm
```
